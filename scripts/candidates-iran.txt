# US-Iran / Middle East candidate sources -- UNMEASURED until probed.
#
#   bash scripts/probe_feeds.sh scripts/candidates-iran.txt
#
# Only entries that come back LIVE with a small age= belong in registry.py.
# An HTTP 200 proves nothing: state.gov and news.un.org both returned 200 with
# ZERO items for months while the system believed it had fast official sources.
#
# Grouped by ROLE, because role decides how a source may be used:
#   SETTLEMENT  the body that actually announces the fact a rule resolves on
#   TRADE       tier-one credible reporting, may authorize a paper/live entry
#   SPEED       state-affiliated or partisan; wakes the bot, never authorizes
#
# The gap worth closing is SETTLEMENT, not more outlets. Groups A-C below are
# named announcing authorities for live rule families (shipping incidents,
# nuclear, talks venue). Groups D-F are additional mirrors of wire copy that
# the existing 222-domain registry and aggregator queries mostly already cover.

# ---------------------------------------------------------------------------
# A. SETTLEMENT -- maritime / Hormuz.  Blockade and chokepoint markets resolve
#    on incident advisories, not commentary.  UKMTO is the authoritative first
#    report for Gulf shipping incidents; PortWatch (already wired) lags 8 days.
# ---------------------------------------------------------------------------
https://www.ukmto.org/rss/advisories
https://www.ukmto.org/feed
https://www.maritime.dot.gov/rss/msci-advisories.xml
https://www.jmic.online/feed

# ---------------------------------------------------------------------------
# B. SETTLEMENT -- nuclear.  Enrichment, inspection and Board-of-Governors
#    markets name the IAEA; its own press feed is the announcing source.
# ---------------------------------------------------------------------------
https://www.iaea.org/feeds/topnews.rss
https://www.iaea.org/rss/news
https://press.un.org/en/rss.xml
https://www.un.org/sc/suborg/en/rss.xml

# ---------------------------------------------------------------------------
# C. SETTLEMENT -- mediator / host states.  "Where will the next round of talks
#    be held" resolves when the HOST government announces.  These agencies are
#    the location bot's missing primary sources (MEDIATOR_ACTORS in registry).
# ---------------------------------------------------------------------------
https://www.qna.org.qa/en/RSS/Feed
https://omannews.gov.om/rss
https://www.spa.gov.sa/rss/rss.php?lang=en
https://www.wam.ae/en/feed.rss
https://www.kuna.net.kw/RSSNewsFeed.aspx?language=en

# ---------------------------------------------------------------------------
# D. SETTLEMENT -- US formal actions.  Executive orders and OFAC designations
#    are structured, timestamped and authoritative for sanctions markets.
#    Federal Register exposes a real JSON/RSS API, unlike state.gov's dead feed.
# ---------------------------------------------------------------------------
https://www.federalregister.gov/api/v1/documents.rss?conditions%5Btype%5D%5B%5D=PRESDOCU
https://ofac.treasury.gov/system/files/rss/recent-actions.xml
https://home.treasury.gov/rss/press-releases.xml
https://www.centcom.mil/DesktopModules/ArticleCS/RSS.ashx?ContentType=1&Site=1000&max=20
